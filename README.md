# R42J – Ready 4 2 Jobs

Lokales, verschlüsseltes Bewerbungs-Tool. Läuft ohne Installation vom USB-Stick in Chrome oder Edge unter Windows und macOS. Kein Server, keine Cloud, kein Konto.

**Stand:** in Entwicklung, noch nicht für echte Bewerbungsdaten geeignet.

## Starten

- Windows: `Start (Windows).cmd` doppelklicken
- macOS: `Start (Mac).command` per Rechtsklick → Öffnen
- Sonst: `Start.html` in Chrome oder Edge öffnen

## Entwicklung

Die App hat keinen Build-Schritt. Sie läuft direkt über `file://`, Bibliotheken liegen in `app/lib/`. Fachliche Grundlage ist [SPEC.md](SPEC.md), die Meilensteine stehen in [PLAN.md](PLAN.md).
