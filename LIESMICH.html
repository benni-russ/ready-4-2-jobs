R42J – Ready 4 2 Jobs

R42J hilft dir bei Bewerbungen: Stammdaten, Lebenslauf, Anschreiben, Versand, Termine und Vorbereitung. Es läuft ohne Installation vom USB-Stick, und deine Daten bleiben verschlüsselt bei dir. English version below.

Du brauchst

  • Windows oder macOS mit Google Chrome oder Microsoft Edge
  • einen USB-Stick oder einen Ordner auf deinem Rechner
  • einen Drucker oder einen sicheren Ort für den Wiederherstellungsschlüssel

Einrichten

  1. Entpacke die ZIP-Datei vollständig auf den Stick. Direkt aus der ZIP-Datei startet R42J nicht.
  2. Starte R42J (siehe unten).

Unter Windows starten

Doppelklicke auf Start (Windows).cmd. Fragt Windows SmartScreen nach, wähle „Weitere Informationen“ und „Trotzdem ausführen“.

Auf dem Mac starten

Der Mac warnt beim ersten Start, weil R42J nicht bei Apple registriert ist.

  1. Klicke mit der rechten Maustaste auf Start (Mac).command und wähle „Öffnen“.
  2. Bestätige die Rückfrage mit „Öffnen“.
  3. Bietet der Mac das nicht an: Öffne „Systemeinstellungen“ → „Datenschutz & Sicherheit“, gehe nach unten zu „Sicherheit“ und klicke auf „Dennoch öffnen“.

Klappt das nicht, öffne Start.html per Rechtsklick → „Öffnen mit“ in Chrome oder Edge. Die Anleitung für den Mac wurde noch nicht auf einem echten Gerät nachgestellt und kann je nach macOS-Version leicht abweichen.

Ordner wählen

R42J fragt beim ersten Start nach seinem Ordner. Klicke auf „Ordner auswählen“, wähle den Ordner mit den Startdateien und erlaube die Änderungen. Daneben entsteht der Ordner daten.

Profil anlegen

Wähle „Neues Profil anlegen“. Der Assistent führt dich durch Passwort, Wiederherstellungsschlüssel und deine ersten Angaben.

Wichtig: Drucke den Wiederherstellungsschlüssel aus und bewahre ihn getrennt vom Stick auf. Ohne Passwort und Schlüssel kommt niemand mehr an deine Daten.

Loslegen

Danach siehst du die Übersicht. Unter „Wissen“ findest du den Artikel „Erste Schritte“.

Update installieren

  1. Sperre R42J und schließe den Tab.
  2. Kopiere den Ordner daten zur Sicherheit auf deinen Rechner.
  3. Entpacke die neue ZIP-Datei und ersetze nur den Ordner app.
  4. Starte R42J wie gewohnt.

Lösche oder ersetze den Ordner daten nie. Dort liegen deine Daten.

Datenschutz

R42J hat keinen Server und kein Konto. Ins Netz geht es nur bei Links, die du selbst anklickst, und bei der Update-Suche, wenn du sie einschaltest. Sie überträgt keine Daten von dir. Die KI-Funktionen laufen über Kopieren und Einfügen in einen Chat deiner Wahl. Persönliche Angaben werden dabei standardmäßig durch Platzhalter ersetzt.

R42J – English

R42J helps you with job applications: base data, CV, cover letter, sending, appointments and preparation. It runs from a USB stick without installation, and your data stays encrypted with you.

You need

  • Windows or macOS with Google Chrome or Microsoft Edge
  • a USB stick or a folder on your computer
  • a printer or a safe place for the recovery key

Set up

  1. Unpack the whole ZIP file to the stick. R42J does not start from inside the ZIP file.
  2. On Windows, double-click Start (Windows).cmd. If SmartScreen asks, choose “More info” and “Run anyway”.
  3. On a Mac, right-click Start (Mac).command, choose “Open” and confirm. If the Mac does not offer this, go to System Settings → Privacy & Security, scroll to Security and click “Open Anyway”. These Mac steps have not been checked on a real device yet and may differ slightly by macOS version.
  4. If neither works, right-click Start.html and open it in Chrome or Edge.
  5. Click “Choose folder”, pick the folder with the start files and allow the changes. The daten folder appears next to it.
  6. Choose “New profile”. The assistant guides you through password, recovery key and first details.

Important: Print the recovery key and keep it away from the stick. Without password and key nobody can reach your data.

Install an update

  1. Lock R42J and close the tab.
  2. Copy the daten folder to your computer to be safe.
  3. Unpack the new ZIP file and replace only the app folder.
  4. Start R42J as usual.

Never delete or replace the daten folder. That is where your data lives.

Privacy

R42J has no server and no account. It only goes online for links you click yourself and for the update check if you turn it on, which transfers none of your data. AI features work by copy and paste into a chat of your choice. Personal details are replaced by placeholders by default.
